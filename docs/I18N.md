# Languages (i18n)

iDID is in English, with Spanish (Español) in progress. This page explains how translation works in the code, what's translated so far, and the glossary for reviewers.

## How it works

- Text is written in English in the code and wrapped in `t('…')` from `app/src/i18n`. The English sentence is the key, so code stays readable and anything not yet translated simply shows in English.
- Placeholders use braces: `t('Support near {name}', { name })`. Use `tn(n, 'one form', 'other form')` for singular and plural.
- For English text defined in lists or constants, mark it with `tx('…')` where it's defined, and translate it with `t(x)` where it's shown.
- Spanish lives in `app/src/i18n/es.ts`.
- **The test `app/src/i18n/i18n.test.ts` fails if a marked string has no Spanish version, or if a translation drops or renames a placeholder.** So any new text in a translated screen needs its Spanish in the same change.
- Language comes from **Settings → Language & prompts → Language**, or the English/Español buttons on the first setup screen. When nothing is chosen, iDID follows the browser: Spanish if the person's first preferred language between English and Spanish is Spanish.
- The choice is stored on the device (unencrypted, like the theme), so the lock screen shows in the right language.
- Dates and times follow the language (`es-US` or `en-US`), and `<html lang>` is set to match.
- Avoid ending a sentence with a time placeholder. Spanish times end in "p.m.", which would give a double period.

**The crisis card in Spanish** uses the 988 Lifeline's own Spanish options, checked on its Spanish page (988lifeline.org/es) in November 2026:
- **Call:** 988, then press 2.
- **Text:** the word AYUDA to 988.
- **Chat:** the Spanish services page.

The Crisis Text Line button only appears in English, because its Spanish options weren't verified.

## Review needed

The Spanish is a careful first draft written for iDID's tone. It has **not yet been reviewed by a native speaker**. Before telling Spanish-speaking users about it, ask a native-speaking clinician or peer specialist (ideally someone with dissociation and trauma experience) to review `es.ts`. A reviewer should check:

- Tone: warm, informal "tú", never clinical or alarming.
- Crisis wording in Pause, the crisis card and the safety plan.
- The terms in the glossary below.
- Gendered forms. The draft uses "listo/a" and "seguro/a" where the person's gender is unknown; some readers prefer "listx" or rewording.
